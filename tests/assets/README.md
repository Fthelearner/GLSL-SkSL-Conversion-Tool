# Assets

Procedurally-generated texture assets for the 119 SKSL shaders. All textures are 1280×720.

## Generated textures

| File | Size | Description |
|---|---|---|
| `input.png` | 24 KB | Demo image (stripes + circles) — primary input for all effects |
| `displacement.png` | 35 KB | RG displacement map — R=dx, G=dy, A=strength, with radial ripples |
| `preblur.png` | 92 KB | Gaussian-blurred input (sigma=8.0) — fallback for all blur intermediates |
| `blur_mask.png` | 58 KB | Blur/gradient control mask — alpha channel = per-pixel blur radius |
| `light_mask.png` | 175 KB | Light intensity mask — R=radial from center, G=highlight lobe, A=combined |
| `noise.png` | 2.1 MB | 4-channel noise/seed — R/G=fbm noise, B=white noise, A=smooth dots |

## Uniform shader → asset mapping

The 56 unique `uniform shader` names across all 119 shaders map to these 6 pre-generated textures:

### Category 1 — Main input image (→ `input.png`)
| Uniform name | Uses | Read channel | Semantic |
|---|---|---|---|
| `image` | 24 | `.rgb` / `.rgba` | Main image to filter |
| `imageInput` | 11 | `.rgb` | Input image (blur/kawase/etc.) |
| `imageShader` | 9 | `.rgb` | Image as shader child |
| `srcImageShader` | 4 | `.rgb` | Source image (gradient/color filters) |
| `inputShader` | 1 | `.rgb` | Input image |
| `originalInput` | 1 | `.rgb` | Original unmodified input |
| `original_tex` | 1 | `.rgb` | Original texture |

### Category 2 — Displacement/distortion (→ `displacement.png`)
| Uniform name | Uses | Read channel | Semantic |
|---|---|---|---|
| `maskEffect` | 1 | `.rg` → direction vector | Displacement distortion map |

### Category 3 — Blurred variants (→ `preblur.png`)
| Uniform name | Uses | Read channel | Semantic |
|---|---|---|---|
| `blurredInput` | 2 | `.rgb` | Blurred input (kawase/mesa mix pass) |
| `edgeBlurredImg` | 2 | `.rgb` | Edge-blurred image (frosted glass) |
| `bgBlurredImg` | 2 | `.rgb` | Background-blurred image (frosted glass) |
| `baseBlurImg` | 1 | `.rgb` | Base blur layer (spatial glass) |
| `blur_tex` | 1 | `.rgb` | Blur texture (blur bubbles rise) |
| `blurImageShader` | 1 | `.rgb` | Blur image (linear gradient blur) |
| `verticalBlurTexture` | 1 | `.rgb` | Vertical blur pass (aurora noise) |
| `blurredSdfImageShader` | 1 | `.rgba` | Blurred SDF (SDF edge light) |
| `blurredSDFInput` | 1 | `.rgba` | Blurred SDF input |
| `imageBlur0`–`imageBlur4` | 5 | `.rgb` | Multi-level blur pyramid (edge light composite) |

### Category 4 — Blur/gradient masks (→ `blur_mask.png`)
| Uniform name | Uses | Read channel | Semantic |
|---|---|---|---|
| `gradientShader` | 5 | `.a` → blur radius | Per-pixel blur radius control |
| `mask` | 4 | `.r` / `.a` | Generic mask (direction light, dispersion) |

| `blur_mask` | 1 | `.a` → blur amount | Blur bubbles mask |

### Category 5 — Light mask (→ `light_mask.png`)
| Uniform name | Uses | Read channel | Semantic |
|---|---|---|---|
| `lightMaskShader` | 2 | `.r` → light intensity | SDF edge light bloom mask |

### Category 6 — Noise/seed (→ `noise.png`)
| Uniform name | Uses | Read channel | Semantic |
|---|---|---|---|
| `u_seeds` | 1 | `.r` → seed value | JFA normal calculation random seeds |
| `auroraNoiseTexture` | 1 | `.rgb` | Aurora noise sampling |

### Not pre-generated — runtime intermediates only

The following uniforms are **runtime-generated** by other shader passes and cannot be meaningfully pre-baked:

| Category | Uniform names | Count | Generated by |
|---|---|---|---|
| SDF shapes | `sdfShape`, `shapeShader`, `sdfShader`, `sdfImageShader`, `sdfImage`, `sdfNormalImg`, `u_sdfTex`, `u_prevD` | ~20 | SDF filters, shape renderers |
| Shape inputs | `pixelmapShader`, `pathShader`, `shape` | ~4 | Pixelmap/path shape generators |
| Transition layers | `left`, `right`, `topLayer`, `bottomLayer`, `image1`, `image2`, `composeImage`, `progressImage`, `loopImage` | ~12 | Transition/blend pipeline |
| Particles/halos | `glowHalo`, `particleHalo`, `singleParticleHalo`, `imageBloom` | ~4 | Particle/halo render passes |
| Precalculation | `precalculationImage` | 3 | Contour diagonal flow light pre-pass |
| Color gradient | `colorGradientShader` | 1 | Color gradient effect output |
| SDF path masks | `u_maskTex` | 1 | SDF path shape pre-pass |

## Regenerating

```bash
cd 2d_effect_code_repositories
uv sync
uv run python src/generate_assets.py [--width 1280] [--height 720]
```
